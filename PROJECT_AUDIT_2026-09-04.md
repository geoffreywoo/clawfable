## Model and creative controls

`ASTRA_CREATIVE_ROLLOUT` is `off` by default (absent/invalid values preserve the current stacks). `geoffrey` opts in only the recognized Geoffrey aliases; `all` is reserved for a successful later promotion. All creative stages, replies, editorial judgment, learning, and voice synthesis resolve the account stack. Classification and source-enrichment utilities retain their existing models. Explicit preview comparison stacks remain independent.

Astra defaults to high reasoning for creative work and learning, medium for judges, and at least 8,192 output/reasoning tokens within existing run deadlines. Inherited `none`/`minimal` settings normalize to `low`; supported efforts run through `max`. No `temperature` is sent. Fallbacks use the same downstream eligibility gates. Traces distinguish requested model, actual model, reasoning, skipped/unavailable providers, incomplete responses, tokens, latency, and estimated cost.

Pricing checked against [OpenAI pricing](https://developers.openai.com/api/docs/pricing) on 2026-09-04: Astra standard uncached input $10/M and output $50/M tokens; over 272k input tokens, input is 2x and output 1.5x. The current `gpt-5.6` alias resolves to `gpt-5.6-sol`, whose documented promotional pricing is $4/M input and $20/M output, with the same long-context multipliers, available at least through 2026-11-21. See [GPT-5.6 Sol](https://developers.openai.com/api/docs/models/gpt-5.6-sol). Estimates retain cache token counts but use uncached input rates; they are not invoice reconciliation. Capability source: [Astra migration guide](https://developers.openai.com/api/docs/guides/latest-model?model=gpt-6-astra).

## Derived history repair

The protected `POST /api/internal/agents/:id/generation/quality/refresh` accepts `{"mode":"derived_only"}`. It acquires the existing account lock, rebuilds learning summaries, and replays experiment reward projections from retained verified evidence. It does not read X, refill or alter the queue, publish, or rewrite the SOUL. Insight synthesis can call the configured learning model. Raw signals, tweets, feedback, and outcomes remain preserved.

Summary derivation version `learning-2026-09-04-v3` records mature/immature counts, recovered edit signal IDs, excluded unverified removal counts, and reward math version `mature-spread-action-2026-09-04-v1`. Mature action rewards are recalculated from measured metrics and current mature baselines, replacing legacy cached calculations only in derived views/projections. Cron rebuilds stale derivation versions. Recovered examples reach subsequent generation context.

Rebuilds cannot recover records already lost to historical races or retention limits. Complete edit pairs are recoverable only when intact lineage and trustworthy original/edited text still exist. Performance maturity depends on actual measurement time, not the current age of a formerly early checkpoint.

## Evaluation and release gates

The frozen evaluation uses 40 packets: 30 Geoffrey and 10 explicitly synthetic other-account profiles. Both stacks receive identical frozen briefs and evidence. Account reference examples are held out from prompt anchors, with their original authorship provenance retained. A timeline reference is not proof of human composition. Primary model fallback invalidates a comparison as Astra evidence. The evaluation records eligibility, ideas, factual failures, copied premises, estimated edit burden, latency, cost, and blinded preference. A score must identify its reviewers; model votes are not human votes and edit estimates are not observed edits.

Promotion requires at least 30 decisive comparisons, at least 60% Astra preference, all 40 comparisons completed, and no hard-gate regression. Empty or unqualified content does not satisfy the gate. Frozen evidence is as of capture, not a claim of current news accuracy.

Reproduce from a validated private snapshot using `npm run eval:astra -- --validate --snapshot FILE`, then `npm run eval:astra -- --run --snapshot FILE --remote-origin https://www.clawfable.com --max-cost-usd 100`. Optional `--concurrency 1..4` runs independent packets concurrently; the default is one, and each packet's alternating model arms stay sequential. Supply `CRON_SECRET` through the local environment, never a command argument. Remote execution sends a hashed gzip packet per arm to the authenticated evaluation endpoint; it enforces 2 MiB compressed/8 MiB expanded limits and preview-only production gates. The first response pins the deployment SHA; later requests reject a changed deployment before generation, and all returned identities are checked. It does not export provider credentials. Snapshot capture and all result files stay under the ignored `.gstack/astra-evaluation/` directory. The cost ceiling stops new arms at observed spend; already-running arms can exceed the remaining estimate. Invalid arms stop new scheduling while active calls drain. An uncertain network result is not automatically retried because it may already have incurred provider cost. Ordered, serialized progress receipts preserve returned paid arms; SIGINT/SIGTERM stop scheduling and drain active work. A hard process kill cannot guarantee receipt persistence.

## Completion and creative-execution repair

The follow-up investigation reproduced a hidden transport behavior with the installed OpenAI SDK and a local fake HTTP provider: one application attempt received a 503 and retried internally before returning 200. Astra now disables SDK retries, letting the explicit model chain record each failure. Astra Responses streaming records the response ID, wire model, status, first event, first output, and last event. Only a full terminal response can supply copy; deltas, premature EOF, status mismatch, abort, and error events cannot become accepted text. This instrumentation distinguishes provider acceptance from completed generation; it does not retroactively establish the cause of older timeouts.

Astra ideation now assigns three separate substantive approaches to independent one-proposition requests: a conviction, a decision/question, and an institutional consequence. Requests rotate across briefs before taking another approach, with at most four concurrent calls and three propositions per brief. The entire Astra idea stage, including retries, shares 120 seconds and respects the remaining 240-second run deadline. Completed propositions survive stage expiry; queued work stops so writers and judges retain time. Exact brief binding, combined normalization, existing semantic deduplication, and proposition caps prevent extra model output from gaining extra selection chances. Creative reasoning remains high. This scheduling change is a hypothesis about completion reliability until the new live receipts establish its effect.

The founder-ownership receipt identified a separate reproducible creative defect: the selected idea's distinctive consequence was an override on everyone still building, but a writer instruction explicitly told the direct-judgment variant to stop before the consequence. All single-call variants were also forced toward the shortest shape. Writers now retain the approved idea's specific stakes and use a natural shape appropriate to its voice anchors. Parsed positive SOUL sections are separated from prohibitions without changing the SOUL. Ideation excludes raw example/prior-post sections even when nested inside malformed anti-goals.

The same founder receipt contained useful critic feedback that could not enter the old near-miss repair path. It requires a substantive critic diagnosis and sufficient remaining time. The repair receives the original critic notes and approved evidence, then passes the same deterministic checks and final critic. Factual failures, copied premises, unavailable judgment, already-mutated drafts, and exhausted deadlines do not qualify. Admission to a rewrite does not change publishing thresholds.
